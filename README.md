Student Grade Tracker

About the Project

Student Grade Tracker is a console-based Java application that helps manage student names, marks, and grades.

The program allows users to enter student details, categorize students based on their marks, and display a summary of all students.

Features

- Enter multiple student names and marks
- Stop student entry using the "exit" command or "no" option
- Categorize students based on their marks
- Assign grades automatically
- Display highest, average, and lowest student categories
- Show a summary of all students
- Identify students who have failed

Grading System

Marks| Grade
Above 75| A
Above 50 and below 75| B
33 to 50| C
Below 33| Fail

Technologies Used

- Java
- ArrayList
- Scanner
- Loops and Conditional Statements

How to Run

1. Install Java JDK.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Compile the Java file:
   
   "javac projectTry4.java"

5. Run the program:
   
   "java projectTry4"
